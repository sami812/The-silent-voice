# The Silent Voice - Smart Chat Backend API

This backend service powers the Smart Chat interface for The Silent Voice application. Built with FastAPI and the Groq LLM API (Llama 3), it is designed to process disconnected words from a computer vision model, translate them into natural English sentences, and generate contextual smart replies for both deaf and hearing users.

## Core Features
- **Computer Vision Integration:** Receives real-time, disconnected sign language words detected by custom Computer Vision models (.h5 / .tflite), acting as the logic layer that converts physical gestures into context-aware natural language.
- **Context-Aware Translation:** Converts raw sign language keywords into grammatically correct human-like English sentences.
- **Smart Replies Engine:** Generates contextual response suggestions for both parties to maintain a fluid conversation.
- **Location-Awareness:** Integrates optional real-time location contexts (e.g., Pharmacy, Street) to dynamically adjust the system's vocabulary and translation accuracy.
- **Automated Emergency SOS:** Intelligently detects dangerous scenarios or medical distress, triggering a boolean flag and an automated, localized Arabic distress message ready for WhatsApp/SMS dispatch.

## API Documentation & Endpoints

### 1. Process Signs (Deaf -> Hearing)
Translates disconnected words captured from the Computer Vision model along with an optional location context, providing a full sentence and 4 suggested replies.

* **URL:** `/api/process-signs`
* **Method:** `POST`
* **Request Body (`location` is optional):**
  ```json
  {
      "words": ["pain", "stomach", "help"],
      "location": "Pharmacy"
  }

```

* **Response:**
```json
{
    "translated_text": "I am experiencing severe stomach pain and need help.",
    "suggested_replies": [
        "Do you need me to call an ambulance?",
        "Please sit down, I will help you.",
        "Are you taking any medication?",
        "I am here for you."
    ],
    "context_type": "Emergency",
    "is_emergency": true,
    "whatsapp_msg": "<Auto-generated Arabic distress message containing situation and location>"
}

```



### 2. Suggest Replies (Hearing -> Deaf)

Takes the text spoken/written by the hearing person and generates 4 smart replies for the deaf person to choose from.

* **URL:** `/api/suggest-replies`
* **Method:** `POST`
* **Request Body (`location` is optional):**
```json
{
    "text": "Your total bill is 150 dollars, sir.",
    "location": "Supermarket"
}

```


* **Response:**
```json
{
    "suggested_replies": [
        "Here you go.",
        "Can I pay with a credit card?",
        "That is quite expensive.",
        "Thank you for your help."
    ]
}

```

## Deployment & Setup Instructions

### Option 1: Running Locally (For Testing)

1. Clone the repository:
```bash
git clone [https://github.com/sami812/The-silent-voice.git](https://github.com/sami812/The-silent-voice.git)
cd The-silent-voice/backend

```


2. Install the required dependencies:
```bash
pip install -r requirements.txt

```


3. Set your Groq API key as an environment variable. Create a file named `.env` in the backend folder and add:
```env
GROQ_API_KEY=your_api_key_here

```


4. Run the FastAPI server:
```bash
uvicorn api.main:app --host 0.0.0.0 --port 8000 --reload

```


5. The API documentation (Swagger UI) will be available at: `http://localhost:8000/docs`

### Option 2: Deploying to Render (Production)

1. Go to [Render Dashboard](https://dashboard.render.com/) and click **New +** -> **Web Service**.
2. Connect this GitHub repository.
3. Configure the service with the following settings:
* **Root Directory:** `backend`
* **Runtime:** `Python 3`
* **Build Command:** `pip install -r requirements.txt`
* **Start Command:** `uvicorn api.main:app --host 0.0.0.0 --port $PORT`


4. Expand **Environment Variables** and add your API Key:
* **Key:** `GROQ_API_KEY`
* **Value:** `(Insert the Groq API Key here)`


5. Click **Create Web Service**. Once deployed, copy the provided `onrender.com` URL to use as the Base URL in the client application.
